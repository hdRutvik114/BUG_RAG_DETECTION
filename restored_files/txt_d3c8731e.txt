# BugIdentifier: Code-RAG Automated Bug Detection & Program Repair Platform

## 1. Executive Summary

**BugIdentifier** is an intelligent Automated Program Repair (APR) and defect detection platform designed for JavaScript and TypeScript codebases. The system bridges static Abstract Syntax Tree (AST) analysis, Retrieval-Augmented Generation (Code-RAG), and Large Language Models (LLMs) to identify logic defects, boundary violations, and asynchronous errors, and automatically synthesize verifiable patches.

## 5. Detailed Component Breakdown

### 5.1 Babel AST Slicer (`backend/core/ast_slicer.py` & `backend/ast_parser.js`)
* **Role**: Parses source files into Abstract Syntax Trees using `@babel/parser`.
* **Operations**:
  - Traverses AST nodes (`FunctionDeclaration`, `FunctionExpression`, `ArrowFunctionExpression`, `ClassMethod`).
  - Extracts exact start/end line bounds and raw source code for each function.
  - Generates numerical AST structural vectors and computes cyclomatic complexity.

### 5.2 Delta-RAG Engine (`backend/core/delta_rag.py`)
* **Role**: Matches sliced functions against 478 verified historical bug-fix pairs.
* **Similarity Formula**:
  $$\text{Score} = 0.40 \times \text{Cosine}(\mathbf{v}_{\text{target}}, \mathbf{v}_{\text{historical}}) + 0.60 \times \text{Cosine}(\mathbf{t}_{\text{target}}, \mathbf{t}_{\text{historical}}) + \text{Defect Heuristic Signals}$$
* **Delta Signatures**: Extracts specific structural code transformations:
  - Added boundary checks (`if (arr.length > 0)`)
  - Added async/await operators (`await fetch()`)
  - Nullish safety operators (`?.`, `??`)
* **Learned Gatekeeper**: Filters clean methods locally before calling LLM APIs, saving cost and reducing latency.

### 5.3 Program Repair Agent (`backend/core/repair_agent.py`)
* **Role**: Synthesizes verified patches for flagged methods.
* **Dual Execution Strategy**:
  1. **Primary**: Google Gemini AI (`gemini-3.6-flash`) instructed with strict target-preservation prompts and historical Delta Signature blueprints.
  2. **Fallback**: Deterministic AST refactoring engine for offline execution or quota resilience.

### 5.4 Frontend Interface (`frontend/src/`)
* **Views**:
  1. **Summary & Improvements**: Executive health grade (A/B/C), quality score, defect breakdown, and actionable engineering best practices.
  2. **Issues & Code Diff**: 3-column workspace with file hierarchy tree, side-by-side Monaco diff viewer, defect explanation, and 1-click patch application.
  3. **Telemetry & Metrics**: Full observability ledger displaying all parsed methods, complexity, AST depth, and gatekeeper decisions.

## 6. How to Run the Platform

### Single-Command Start (Backend + Frontend):
```powershell
python run_app.py
```

### Or Run in Separate Terminals:

#### Terminal 1 — Backend (FastAPI):
```powershell
python -m uvicorn backend.main:app --host 127.0.0.1 --port 8000 --reload
```
*API Documentation:* `http://127.0.0.1:8000/docs`

#### Terminal 2 — Frontend (React / Vite):
```powershell
cd frontend
npm run dev
```
*Application Dashboard:* `http://localhost:5173`
