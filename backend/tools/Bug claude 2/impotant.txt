Why the Dataset Has 1,936 Clean Rows:
Deduplication: Multi-file commits often changed 5 files for a single bug, producing identical code snippets. We deduplicated these so the model doesn't overfit on duplicate code.
Zero-Diff Filtering: Commits where buggy_code == fixed_code (e.g. whitespace/formatting changes only) were removed because there was no bug fix logic to extract.
AST Quality: Snippets under 15 characters (e.g., {}) were removed so every sample has valid AST syntax context.
