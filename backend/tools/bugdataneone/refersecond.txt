==========================================================
CLASSIFICATION RULES
==========================================================

Classify based on the ACTUAL CODE CHANGE, not only commit message.

Examples:

Adding await
→ async_error

Adding try/catch
→ exception_handling

Adding null checks or optional chaining
→ null_pointer

Fixing API arguments
→ api_misuse

Changing > to >=, index+1, loop bounds
→ off_by_one

Adding validation before processing
→ input_validation

Fixing React state updates/useEffect dependencies
→ state_management

Fixing type conversions/ObjectId/parsing
→ type_error

Adding sanitization/escaping/auth/security middleware
→ security_vulnerability

Fixing algorithm logic
→ logic_error

Closing DB/file/socket/stream/resources
→ resource_leak

Optimizing rendering, queries, loops, memoization
→ performance_issue

If multiple bug types appear, classify according to the PRIMARY bug fixed.

Never invent labels.
